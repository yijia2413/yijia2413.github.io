Harness——剑桥词典的定义

名词。一套带子和扣具，用来控制或固定一个人、一只动物、或一件东西。

动词。控制某物，通常是为了用上它的力量。

我想起 harness，先想起中学时套上那一套带子和扣，再往学校的岩壁上爬。我最多算个平庸的攀岩者。

Royal Robbins 在 El Capitan 上，安全带上挂满这次攀登要用的工具。照片：Tom Frost。原文用的同一张。

不过，要是你这阵子一直灌着 AI 新闻流，你脑子里的典型 harness 可能已经是 agent harness 了。这篇不是写给你的。

这篇写给可能想知道 agent harness 是什么、又不知道、还不好意思问的人。

我们先回到攀岩。

去攀岩为什么要套上安全带？首先，它托住你，让你安全。做法是把你连到快挂和绳子上，这些东西拦住坠落、放慢节奏、规定路线。你还可以往安全带上挂别的工具：粉袋、岩钉工具、快挂。

换一座山、换一条路线，这套带子可以带走。地形不同，你甚至可以改安全带，以及环上挂什么。攀岩安全带是能改的。杂技演员和 arborist 也用同类装备。拥有它的人能把它做成自己的。

攀岩安全带和 agent harness，在结构和功能上都对得上。

1Agent harness

别人写过（写得太简）：Agent = Model + Harness。这里的 Harness 指的是 agent harness。可 agent harness 是什么？Agent harness 用 AI 模型做出 AI agent，最早一批用在写代码。现在各类 AI agent 的核心都坐着一层 harness。弄懂它怎么工作，有助于弄懂 AI agent 是什么。

An agent harness is a piece of software that provides an environment for an AI model to operate within.

和大多数 AI 模型不同，你作为终端用户可以拥有自己的 agent harness。

软件工程师常常用电脑上的终端，直接跟 Pi 这类 harness 说话。也有 harness 走别的界面：OpenClaw 用 iMessage、聊天软件或邮件。我们自己的 harness Lefos 主要走邮件。界面不论，harness 一般做四件事。第一，给一套说明，管模型怎么回应，通常叫「系统提示」。第二，描述并提供一套工具，模型可以调用它们来回应用户。第三，建立一套框架，管模型怎么表现。这套框架干很多事，其中一件主轴是建立「agentic loop」。最后，大多数 harness 还提供一层翻译，让同一套带子能接各种 AI 模型。

2四件事

一、系统提示

大多数 AI 模型训练时已经吃进一套规则和指南。最出名的大概是 Claude Opus 4.5 那份公开过的 soul document，用来告诉模型自己是谁、该怎么做。Harness 里的系统提示跟这个像，但嵌得没那么深。更像新员工第一天拿到的说明。它还没把这些说明内化，但做这摊活时知道该照着走。系统提示会跟每一次用户请求一起注入对话，在这个 harness 的上下文里，让模型表现得合适。

二、工具

工具是一套写在代码里的能力，模型可以「调用」。Harness 负责描述这些工具，也提供工具本身的软件。例子包括网页搜索、写代码并执行、写一封邮件。关键在于：harness 通常不规定模型何时用、怎么用。它只是把工具摆出来，描述清楚，让模型自己决定。

三、Agentic loop

现在有一个坐在 harness 里的模型，带着一套说明和一套工具。假定这套 harness 走邮件，工具就是上面说的那些（网页搜索、写代码、写邮件），用户请它比较附近小学的排名和考试成绩，给建议。它会怎么表现？

它先试着理解这个请求（或者说「提示」）。它用预训练和权重理解「小学」是什么、「附近」指哪、「排名」用户大概在乎什么。然后构造网页搜索，去抓新数据。这些结果怎么办？坐在 harness 里，模型能拿它们对照最初的请求。它可能判断第一次没抓对，或者不够，于是自己决定再搜一次。根据自己的评估再调一次工具，这是「循环」第一个清楚的例子。

假定它把相关数据都收齐了。模型决定用「写代码」做一张表。表格也是代码。它用这个工具做计算、排版，让结果能看懂。再把表拿回最初的提示上对照。数据还不满意，它可能再「转一圈」，回去再搜。它觉得够了，就调用写邮件：让 AI 审一遍发现、写摘要、写信、带上表格当附件。模型再看终稿，认为活干完了。「agentic loop」合上。几秒之内，用户收到一封邮件，正文是摘要和建议，附件是那张表。

想看循环在实际里长什么样，可以点开一次 Pi 会话。

四、翻译层

翻译层让同一套 harness 能接不同的 AI 模型。有时 harness 会在同一次循环里换模型，因为不同模型擅长不同步骤。翻译层也把控制交给终端用户。意思是：你可以带着自己的 harness，去接 Anthropic 的模型、OpenAI 的模型，或者去试那些按每次任务成本往往更划算的开源权重模型。

这一层把力量和杠杆从实验室挪到用户手里。人能拥有 harness，并在自己的电脑上跑，就还握着自己的主动权。他们还能把工具做成自己的，把会话留在本地——时间长了，这些会话会变成他们和机器的通信记录。用户面对的是一套 harness，而不是实验室发布的一个应用，选择还在自己这边。上面那个邮件例子里，用户可以把同一封邮件分别丢给 OpenAI 的模型、Anthropic 的模型、一个开源权重模型，然后比较结果、每次任务的成本，答案也留在同一处，而不是三份答案分别躺在三个应用里。

3把它变成你的

和模型本身不同，你可以拥有并改 harness。像攀岩安全带一样，你可以把它做成自己的。人们喜欢 Pi 这一点。Pi 是一套很薄的 agent harness。系统提示短。工具很少。开箱就是为了把自己让开。可人用着 Pi，会按自己的方式延长它、捏它。他们改系统提示，或者做一个贴合某个流程的 扩展，再分享出去。Pi 用户互相分享了超过 5,000 个扩展。Pi 也免费开源。它住在你自己的笔记本上。于是人手里有了一件自己拥有的工具，跑在自己的硬件上，可以拿它去用 AI。

4开源、中立、人还握着锤子

Harness 一开始并不开源，也不中立。第一款流行的 agent harness 是 Claude Code。它做成在本地用 Claude 写代码的应用，没有做成对各种模型一视同仁的翻译层。从那以后，免费开源的 agent harness 多了起来：OpenClaw、OpenCode、Hermes、Pi。在 Earendil，我们把 Pi 做成中立的，把能力和选择、自由交给 Pi 的用户。我们也在想，怎样把 harness 带来的好处和主动权，扩到更宽的一群人。

很多人眼下担心越来越大的 AI 公司的力量和影响。其中一些人可能选择完全躲开 AI。我们在 Earendil 相信，可以靠做软件和开放协议来加强人的主动权：搭桥跨过分裂和无知，培养能持久的快乐和理解。我们不会靠无视今天已经存在的技术来做到这一点，而是看清楚、握紧，去驾驭它们；确保是我们握着锤子，锤子不握着我们。
